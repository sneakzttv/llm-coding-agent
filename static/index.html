THE TRUST BOUNDARY

      
A recipe editor, not a host-code executor.

      

        
What can change
A JSON list of five known string operations in a new owned sample workspace. The model cannot write fixtures, Python, paths, or commands.

        
What actually runs
A fixed, checked-in Python unittest runner interprets the validated recipe. Passing three fixtures is evidence about those examples, not a proof of general correctness.

        
What this is not
No LangChain, LangGraph, GitHub API, repository editing, arbitrary task solving, or OS sandbox. Local users and the checked-in source are trusted. See README for deployment limits.
